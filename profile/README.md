| Ваша задача | Чем поможем |
| --- | --- |
| Сотрудники вручную переносят данные из документов | Распознавание, проверка и передача данных в учётную систему. |

### Как вы контролируете проект

1. **До разработки:** разбираем задачу, подписываем NDA, согласовываем объём, архитектуру и оценку.
2. **Во время работы:** выделенная команда, прямая связь с инженерами и еженедельные демонстрации.
3. **При запуске:** развёртывание, исходный код, документация и передача знаний вашей команде.
4. **После запуска:** сопровождение по согласованным условиям.
